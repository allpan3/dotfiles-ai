A cached value can avoid a database request

Illustrative code. Cache entries are assumed valid; expiry and invalidation are outside this example.

Return a cached value before reading storage

const value = cache.get(key);
if (value !== undefined) return value;
return database.read(key);

A successful lookup returns immediately. A missing value falls back to the database.

Assumptions behind this example

The cache lookup is synchronous, and undefined means a missing entry. Check the real API and freshness rules before applying this pattern.
